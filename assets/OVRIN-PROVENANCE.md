The owned-domains image is the existing OVRIN working model, copied byte for byte from `original working-model artifact / OVRIN_OWNED_DOMAINS.png`. StackMap uses its original three-face, four-layer composition and adds selectable regions. Conceptual placement does not assert runtime dependency or privilege.

Icons under `icons/` are Lucide glyphs from the published npm package `lucide-static` 1.52.0 (ISC licence, text in
`icons/LICENSE`), downloaded with `npm pack lucide-static` on 5 October 2026 (no install). 32 of its SVG files are
shipped; each has `stroke-width` set to 1.5 and `stroke` set to white so `SIcon.qml` can colourise it with
MultiEffect. No other change to the drawings.
`icons/calendar.svg` is drawn from the path data of Lucide 1.8.0 (`lucide`, ISC, same licence) found offline on 28 October 2026 in the local Codex runtime's `node_modules/lucide/dist/esm/icons/calendar.js`, written in the shape of the other 32 files (stroke white, `stroke-width` 1.5) with no change to the drawing.
